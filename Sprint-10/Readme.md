# 🚀 Sprint 9 – Lightning Web Components (LWC)

## 📌 Overview

Sprint 9 focuses on building user experiences using **Lightning Web Components (LWC)** and connecting the Salesforce UI with the Apex and Service Layer developed in previous sprints.

The sprint covers both **LWC fundamentals** and **interactive business workflows** using the Student Placement Management System.

## 🎯 Topics Covered

- Lightning Web Components structure
- HTML, JavaScript and Metadata
- Data Binding
- User Events
- Lightning Data Service
- Wire Service
- Apex integration
- Component Lifecycle
- Eligible Jobs Component
- Imperative Apex
- Apply Job Workflow
- Success, Loading, Empty and Error States
- Parent-Child Components
- Custom Events
- UI Refresh
- Debugging LWC applications

## 🛠️ Technologies Used

- Salesforce
- Lightning Web Components (LWC)
- HTML
- JavaScript
- Apex
- SOQL
- DML
- Lightning Data Service
- Wire Service
