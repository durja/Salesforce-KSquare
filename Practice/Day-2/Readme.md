# 🚀 Salesforce Interview Readiness Bootcamp – Day 2

## 📌 Overview

Day 2 focused on designing and implementing **Apex Triggers** based on real-world business requirements. I learned how to write **bulkified triggers**, follow Salesforce **Governor Limits**, and implement the **Trigger Handler Pattern** while applying business validations.

---

## 📚 Topics Covered

* Apex Triggers
* Before vs After Triggers
* Governor Limits
* Bulkification
* Trigger Context Variables
* List, Set & Map
* Trigger Handler Pattern
* SOQL Best Practices

---

## 💻 What I Learned

* Developed a **Before Insert** trigger to automate business validations.
* Prevented duplicate job applications.
* Validated student eligibility using CGPA.
* Restricted applications submitted after the job deadline.
* Automatically assigned the **"Applied"** status to new records.
* Bulkified the trigger using **Lists, Sets, and Maps**.
* Followed the **Trigger Handler Pattern** to separate business logic from the trigger.
