# 🚀 Salesforce Interview Readiness Bootcamp – Day 3

## 📌 Overview

Day 3 focused on **Salesforce automation using Flows and Validation Rules**. I learned how to automate business processes with **Record-Triggered Flows**, enforce data quality using **Validation Rules**, and decide when to use **Flow** or **Apex Trigger** based on different business requirements.

---

## 📚 Topics Covered

* Record-Triggered Flows
* Validation Rules
* Flow Builder
* Email Automation
* Flow vs Trigger
* Before-Save & After-Save Flows
* Declarative Automation

---

## 💻 What I Learned

* Built a **Record-Triggered Flow** to automatically populate the Application Date.
* Configured an email notification to the Placement Officer when an application is created.
* Created Validation Rules to validate CGPA, application date, and mandatory fields.
* Implemented automatic Offer Letter creation when an application's status changes to **Selected**.
* Compared **Flow** and **Apex Triggers** to understand the best solution for different business scenarios.
* Explored Salesforce's order of execution and automation best practices.

---

## 🛠️ Technologies Used

* Salesforce Flow Builder
* Record-Triggered Flow
* Validation Rules
* Flow Actions (Email)
* Salesforce Playground

## 🎯 Outcome

This assignment improved my understanding of Salesforce declarative automation by strengthening my skills in Flow Builder, Validation Rules, and business process automation while learning when to choose Flow over Apex for efficient and scalable solutions.
