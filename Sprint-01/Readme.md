# 🚀 Sprint 01 – Data Modeling, Apex & SOQL

## 📌 Overview

This sprint focused on strengthening Salesforce fundamentals through hands-on practice. I designed a custom data model, practiced Apex programming, executed SOQL queries, implemented Apex Triggers with the Trigger Handler pattern, and built my first Lightning Web Component using `@wire`.

---

## 📚 Topics Covered

- Data Modeling
- Object Relationships
- Apex Basics
- SOQL Queries
- Apex Triggers
- Trigger Handler Pattern
- Lightning Web Components (LWC)

---

## 💻 Key Activities

- Created custom objects and relationships.
- Practiced Apex using Execute Anonymous.
- Wrote and tested SOQL queries.
- Developed Apex Triggers for business validations.
- Implemented the Trigger Handler pattern.
- Built an LWC to display custom object records.

---

## 🛠️ Technologies Used

- Salesforce Playground
- Apex
- SOQL
- Lightning Web Components (LWC)
- Lightning App Builder
- VS Code
- Salesforce CLI

---

## 🎯 Outcome

This sprint strengthened my understanding of Salesforce development fundamentals, including Apex programming, SOQL querying, Trigger development, and building basic Lightning Web Components.
