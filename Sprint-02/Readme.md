# 🚀 Sprint 02 – Apex Triggers & Governor Limits

## 📌 Overview

In this sprint, I focused on implementing business logic using Apex Triggers and understanding Salesforce Governor Limits. I designed a trigger based on real-world business requirements, applied validation logic, prevented duplicate records, and followed Salesforce best practices using the Trigger Handler Pattern and bulkification techniques.

---

## 📚 Topics Covered

* Apex Triggers
* Before Insert Trigger
* Trigger Context Variables
* Governor Limits
* Bulkification
* Trigger Handler Pattern
* Collections (List, Set, Map)
* SOQL Best Practices

---

## 💻 What I Learned

* Designed business logic based on application requirements.
* Created a **Before Insert** trigger to validate records before saving.
* Prevented duplicate applications.
* Validated eligibility based on business rules.
* Automatically assigned default status values.
* Implemented the Trigger Handler Pattern to separate business logic from the trigger.
* Bulkified the trigger using Lists, Sets, and Maps to avoid SOQL and DML operations inside loops.
* Learned how Governor Limits affect Apex development and how to write scalable code.
