# 🚀 Sprint 02 – Collections, Governor Limits & Asynchronous Apex

## 📌 Overview

In this sprint, I focused on writing scalable and efficient Apex code by learning Salesforce collections, Governor Limits, bulkification, asynchronous processing, and Lightning Web Component (LWC) communication. I practiced writing optimized Apex code using Lists, Sets, and Maps while following Salesforce best practices.

---

## 📚 Topics Covered

- Apex Collections (List, Set, Map)
- Governor Limits
- Bulkification
- SOQL Best Practices
- Apex Triggers
- Trigger Handler Pattern
- Asynchronous Apex (@future)
- Queueable Apex (Introduction)
- LWC Parent-to-Child Communication
- LWC Child-to-Parent Communication

---

## 💻 What I Learned

- Practiced using **List**, **Set**, and **Map** collections in Apex.
- Understood Salesforce Governor Limits and why optimized code is important.
- Created an intentionally inefficient trigger to observe Governor Limit exceptions.
- Refactored the trigger using **Sets** and **Maps** to create a bulkified solution.
- Learned to avoid SOQL and DML operations inside loops.
- Implemented a simple **@future** method for asynchronous processing.
- Executed asynchronous jobs and verified their execution through the **Apex Jobs** page.
- Built Lightning Web Components demonstrating **Parent-to-Child** communication using `@api` and **Child-to-Parent** communication using Custom Events.
