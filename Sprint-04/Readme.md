# 🚀 Sprint 03 – My First Lightning Web Component (LWC)

## 📌 Overview

In this sprint, I built my first Lightning Web Component (LWC) for the Placement Management System. I learned how to create a user interface using HTML, JavaScript, and CSS, implement data binding, handle button events, and deploy the component to a Lightning Page.

---

## 📚 Topics Covered

- Lightning Web Components (LWC)
- HTML, JavaScript & CSS
- Data Binding
- Event Handling
- Lightning App Builder

---

## 💻 What I Built

- Created a **placementHome** Lightning Web Component.
- Displayed student details (Name, ID, and Department).
- Added a **Show Welcome Message** button.
- Added an **Apply** button to change the application status from **Not Applied** to **Applied**.
- Built a simple **Placement Portal Dashboard** displaying Today's Date, Companies, Jobs, and Applications Submitted.
- Deployed the component to a Lightning Page.

---

## ❓ README Questions

### 1. What is LWC?
LWC (Lightning Web Components) is Salesforce's modern framework for building fast and reusable user interfaces using web standards.

### 2. What did you build?
I built a **Placement Portal** component that displays student information, placement statistics, a welcome message, and application status.

### 3. Which file contains HTML?
`placementHome.html`

### 4. Which file contains JavaScript?
`placementHome.js`

### 5. What did you learn today?
I learned the structure of an LWC, data binding, event handling, component deployment, and how HTML, CSS, and JavaScript work together in Salesforce.
