# 🚀 Sprint 02 – Validation Rules, Flows & Declarative Automation

## 📌 Overview

This sprint focused on Salesforce declarative automation using **Validation Rules** and **Record-Triggered Flows**. I learned how to automate business processes, improve data quality, and choose the right automation tool based on business requirements.

---

## 📚 Topics Covered

- Validation Rules
- Record-Triggered Flow
- Flow Builder
- Flow vs Trigger
- Before-Save & After-Save Flows

---

## 💻 What I Implemented

- Built a **Record-Triggered Flow** to automatically populate the Application Date.
- Configured an **Email Action** to notify the Placement Officer.
- Created Validation Rules for:
  - Student CGPA validation
  - Application Date validation
  - Mandatory field validation
- Compared **Validation Rules**, **Flows**, and **Apex Triggers** for different business scenarios.
